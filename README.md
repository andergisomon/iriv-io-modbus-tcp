# iriv-io-modbus-tcp
Modbus/TCP firmware for the Cytron IRIV IO.

# Attention: Cybersecurity
I'm not gonna implement Modbus TLS any time soon, consider using [stunnel](https://www.stunnel.org) to tunnel Modbus/TCP traffic over TLS/SSL. It's also under the GNU GPL v2. Secure your networks and show them some love.
